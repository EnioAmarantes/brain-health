# Domínio

## Patient

Representa uma pessoa que busca ajuda profissional, podendo estar logado ou fazer isso de forma anônima.

### Responsabilidades

- Realizar triagem
- Visualizar recomendações

---

## Professional

Representa um profissional da saúde mental.

### Atributos

- Nome
- Registro profissional
- Especialidades
- Cidade
- Estado
- WhatsApp

### Responsabilidades

- Receber encaminhamentos
- Gerenciar perfil

---

## Clinic

Representa uma clínica parceira.

### Responsabilidades

- Gerenciar profissionais
- Receber encaminhamentos

---

## Triage

Representa uma triagem realizada.

### Dados

- Data
- Resultado
- Tags
- Resumo

---

## Lead

Representa um encaminhamento.

### Dados

- Profissional
- Triagem
- Data

---

## Specialty

Representa uma especialidade.

Exemplos:

- Ansiedade
- Relacionamentos
- Luto
- Depressão
- Casal
- Infantil
